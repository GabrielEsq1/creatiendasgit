🏪 Demo del Widget Creatiendas

Esta es una página de ejemplo que muestra cómo se ve el widget embebido.

📋 Instrucciones:

  1. Mira la esquina inferior derecha
  2. Haz clic en el botón "🏪 Creatiendas"
  3. Se abrirá un popup con 3 pestañas:
    • Login - Para iniciar sesión
    • Monedero - Para recargar saldo con PayPal
    • Chat B2B - Para mensajería empresarial

💻 Para Usar en Tu Sitio Web:

Copia el archivo widget-snippet.html y pega el código antes del </body> de tu página.

🎨 Personalización:

  • Cambia CREATIENDAS_URL a tu dominio de producción
  • Personaliza colores en los estilos inline
  • Ajusta la posición del botón (bottom, right, etc.)

✨ Características:

  • ✅ Botón flotante responsive
  • ✅ Modal con animaciones suaves
  • ✅ 3 pestañas integradas
  • ✅ PayPal completamente funcional
  • ✅ Compatible con cualquier sitio web
  • ✅ Sin dependencias externas
